## 5.1.1 Current Build Summary

Cheese v4 is built around the LEGO MINDSTORMS EV3 platform, with an Arduino Nano and HuskyLens added for the vision system.

<div align="center">

| Build Property | Current Cheese v4 |
| :--- | :--- |
| **Main controller** | LEGO EV3 Intelligent Brick |
| **Power source** | EV3 Rechargeable Battery |
| **Drive motor** | 1 EV3 Large Servo Motor |
| **Steering motor** | 1 EV3 Medium Servo Motor |
| **Ultrasonic sensors** | 3 |
| **Color sensors** | 1 |
| **Vision sensor** | 1 HuskyLens |
| **Vision bridge** | 1 Arduino Nano |
| **Steering system** | Front Ackermann steering |
| **Drive system** | Rear-wheel propulsion |
| **Current measured mass** | **666 g** |
| **Auxiliary lighting** | Not used in v4 |

</div>

## 5.1.3 Main Controller — LEGO EV3 Intelligent Brick

<p align="center">
  <a href="https://www.bricklink.com/v2/catalog/catalogitem.page?S=45500">
    <img src="https://img.bricklink.com/ItemImage/ST/0/45500-1.t1.png" width="190" alt="LEGO EV3 Intelligent Brick">
  </a>
</p>

<p align="center">
  <em>LEGO EV3 Intelligent Brick — external reference image, BrickLink.</em>
</p>

The EV3 Intelligent Brick is the main controller of Cheese.

Its responsibilities include:

- running the navigation program,
- reading all EV3 sensors,
- controlling the Large Motor,
- controlling the Medium Motor,
- receiving vision information from the Arduino Nano,
- managing Open Challenge navigation,
- and coordinating obstacle behavior.

### Cheese v4 placement

<p align="center">
  <img src="../../v-photos/v4/ev3_brick_top_v4.jpg" width="62%" alt="EV3 Brick installed on Cheese v4">
</p>

The Brick is mounted flatter than in earlier Cheese versions, with the screen facing upward for easier inspection and operation.

## 5.1.4 Power Supply — EV3 Rechargeable Battery

<p align="center">
  <a href="https://www.bricklink.com/v2/catalog/catalogitem.page?S=45501">
    <img src="https://img.bricklink.com/ItemImage/ST/0/45501-1.t1.png" width="190" alt="EV3 Rechargeable Battery">
  </a>
</p>

<p align="center">
  <em>LEGO EV3 Rechargeable DC Battery — external reference image, BrickLink.</em>
</p>

The EV3 Rechargeable Battery supplies the main electrical power for Cheese.

The battery powers:

- the EV3 Brick,
- both motors,
- EV3 sensors,
- and the connected control architecture.

Battery condition can influence motor response and therefore affects calibration consistency.

<p align="center">
  <img src="../../v-photos/v4/ev3_battery_access_v4.jpg" width="62%" alt="Cheese v4 EV3 battery access">
</p>

The v4 structure keeps the battery accessible so it can be charged without major disassembly.

## 5.1.7 Ultrasonic Sensors

<p align="center">
  <a href="https://www.bricklink.com/v2/catalog/catalogitem.page?S=45504">

<p align="center">
  <em>LEGO EV3 Ultrasonic Sensor 45504 — external reference image, BrickLink.</em>
</p>

Cheese v4 uses **three ultrasonic sensors**.

<div align="center">

| Position | EV3 Input | Function |
| :--- | :---: | :--- |
| **Left** | Input 1 | Left-wall distance |
| **Right** | Input 2 | Right-wall distance |
| **Front** | Input 3 | Forward safety and recovery |

</div>

### Left and right sensors

<p align="center">
  <img src="../../v-photos/v4/side_sensor_layout_v4.jpg" width="70%" alt="Cheese v4 side ultrasonic sensors">
</p>

The two lateral sensors provide wall-distance information to the Open navigation controller.

### Front sensor

<p align="center">
  <img src="../../v-photos/v4/sensor_placement_front_v4.jpg" width="58%" alt="Cheese v4 front ultrasonic sensor">
</p>

The front sensor supports forward-wall detection and reverse-recovery behavior.

The placement of these sensors is considered critical.

<p align="center">
  <strong>Sensor Geometry → Distance Measurement → Steering Decision</strong>
</p>

Changing their height or angle can require PID recalibration.

<p align="center">
  <em>LEGO EV3 Color Sensor 45506 — external reference image, BrickLink.</em>

The Color Sensor is used to identify floor-color events used by the Open Challenge curve-counting logic.

<p align="center">
  <img src="../../v-photos/v4/color_sensor_front_layout_v4.jpg" width="58%" alt="Cheese v4 floor-facing Color Sensor">

<p align="center">
  <img src="../../v-photos/v4/color_sensor_floor_gap_v4.jpg" width="58%" alt="Cheese v4 Color Sensor floor gap">

## 5.1.13 Ackermann Steering Assembly

<p align="center">
  <img src="../../v-photos/v4/ackerman_steering_top_v4.jpg" width="72%" alt="Cheese v4 Ackermann steering">
</p>

The steering system is made from LEGO Technic elements rather than a single purchased component.

Main elements include:

- Medium Motor,
- steering axle,
- steering linkage,
- front wheel supports,
- axles,
- bushings,
- and structural beams.

The geometry matters as much as the parts themselves.

<p align="center">

</p>

## 5.1.18 v3 → v4 Component Transition

Cheese v4 reused the systems that were still useful while modifying or removing components that created unnecessary mass or complexity.

<div align="center">

| Carried Over | Modified / Repositioned | Removed |
| :--- | :--- | :--- |
| EV3 Brick | EV3 orientation | Large camera structure |
| EV3 Battery | Large Motor orientation | Auxiliary lights |
| Large Motor | HuskyLens position | Lamp mounts |
| Medium Motor | Ultrasonic placement | External lighting support |
| Color Sensor | Color Sensor floor gap | Lighting wiring |
| Ultrasonic Sensors | Front wheel system | Upper tower structure |
| HuskyLens | Nano USB cable | Extra liftarms |
| Arduino Nano | Cable organization | Extra pins |
| Rear wheels | Overall chassis layout | Extra axles |
| Useful Technic pieces | Steering integration | Redundant supports |

</div>

<p align="center">

## 5.1.20 Replacement Rules

A reproducible robot does not require every cosmetic LEGO element to be identical.

However, functional geometry should remain consistent.

<div align="center">

| Proposed Change | Safe Without Recalibration? | Reason |
| :--- | :---: | :--- |
| Same liftarm in another color | Yes | Geometry unchanged |
| Equivalent pin color | Yes | Connection unchanged |
| Different cable retention | Usually | Does not alter motion |
| Minor extra reinforcement | Usually | Must not change geometry |
| Different Nano support | Usually | Must remain secure |
| Different ultrasonic position | No | Changes measurements |
| Different Color Sensor height | No | Changes floor reading |
| Different wheel diameter | No | Changes robot behavior |
| Different steering linkage | No | Changes turning geometry |
| Different motor type | No | Changes actuation |
| Different camera angle | No | Changes obstacle detection timing |

</div>

## 5.1.23 Reproducibility Checklist

Before considering a Cheese v4 reconstruction complete:

- [ ] EV3 Brick installed securely
- [ ] EV3 Battery accessible
- [ ] Large Motor connected to Output B
- [ ] Medium Motor connected to Output A
- [ ] Ackermann linkage moves freely
- [ ] Rear drivetrain rotates freely
- [ ] Two front SPIKE wheel assemblies installed
- [ ] Rear drive wheels aligned
- [ ] Left Ultrasonic connected to Input 1
- [ ] Right Ultrasonic connected to Input 2
- [ ] Front Ultrasonic connected to Input 3
- [ ] Color Sensor connected to Input 4
- [ ] Color Sensor has correct floor clearance
- [ ] HuskyLens faces forward
- [ ] Camera angle checked
- [ ] Arduino Nano connected
- [ ] HuskyLens I²C wiring checked
- [ ] Nano USB connection checked
- [ ] Wiring does not interfere with steering
- [ ] Wiring does not touch wheels
- [ ] Chassis remains rigid
- [ ] Battery is sufficiently charged
