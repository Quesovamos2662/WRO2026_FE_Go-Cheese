<p align="center">
  <strong>
    Keep Necessary Components → Improve Their Placement → Remove Unnecessary Structure
  </strong>
</p>

## 5.1.3 Main Controller and Power System

### EV3 Intelligent Brick

<p align="center">
  <a href="https://www.bricklink.com/v2/catalog/catalogitem.page?S=45500-1">

  </a>
</p>

<p align="center">
  <em>External component reference — LEGO EV3 Intelligent Brick 45500.</em>

The EV3 Brick is the main controller of Cheese.

It:

- executes the autonomous program,
- reads EV3 sensors,
- controls both motors,
- handles Open Challenge navigation,
- and receives processed vision information through the Nano bridge.

## 5.1.6 Ackermann Steering Components

Cheese does not use tank steering.

The Medium Motor controls a LEGO Technic linkage that turns the two front wheels.

<p align="center">
  <a href="https://www.bricklink.com/v2/catalog/catalogitem.page?P=64781">
    <img src="https://img.bricklink.com/ItemImage/PN/11/64781.png"
         width="190"
         alt="Technic steering rack reference">
  </a>
</p>

<p align="center">
  <em>
    Representative online reference for a Technic steering component.
    Cheese's steering assembly itself is made from several Technic elements.
  </em>
</p>

<p align="center">
  <img src="../../v-photos/v4/ackerman_steering_top_v4.jpg"
       width="72%"
       alt="Cheese v4 Ackermann steering">
</p>

Changing the steering geometry can change:

- maximum steering angle,
- inside-wheel angle,
- outside-wheel angle,
- turning radius,
- and curve behavior.

For that reason, steering geometry is considered part of the reproducible BOM.

| HuskyLens | Nano USB cable | Extra liftarms |

## 5.1.17 Replacement Rules

<div align="center">

| Proposed Substitution | Recalibration Likely? | Reason |
| :--- | :---: | :--- |
| Same liftarm geometry in another color | No | Geometry remains the same |
| Equivalent pin in another color | No | Connection remains equivalent |
| Different cable-retention method | Usually no | Does not affect robot geometry |
| Minor additional reinforcement | Usually no | Must not shift sensors or mechanisms |
| Different Nano support method | Usually no | Must remain secure |
| Different ultrasonic position | **Yes** | Changes wall measurements |
| Different Color Sensor height | **Yes** | Changes floor reading |
| Different wheel diameter | **Yes** | Changes physical behavior |
| Different steering linkage | **Yes** | Changes turning geometry |
| Different motor type | **Yes** | Changes actuation |
| Different camera angle | **Yes** | Changes obstacle detection timing |

</div>

Before considering a Cheese v4 reconstruction complete:

- [ ] EV3 Brick securely installed
- [ ] EV3 Battery installed and accessible
- [ ] Large Motor connected to Output B
- [ ] Medium Motor connected to Output A
- [ ] Rear drivetrain rotates freely
- [ ] Ackermann linkage moves without binding
- [ ] Two front SPIKE wheel assemblies installed
- [ ] Rear drive wheels aligned
- [ ] Left Ultrasonic Sensor connected to Input 1
- [ ] Right Ultrasonic Sensor connected to Input 2
- [ ] Front Ultrasonic Sensor connected to Input 3
- [ ] Color Sensor connected to Input 4
- [ ] Color Sensor floor clearance checked
- [ ] HuskyLens installed in the correct forward position
- [ ] HuskyLens angle checked
- [ ] Arduino Nano connected
- [ ] HuskyLens-to-Nano wiring checked
- [ ] Nano-to-EV3 USB connection checked
- [ ] Wiring clear of steering movement
- [ ] Wiring clear of wheels

- [ ] Battery adequately charged
- [ ] Sensor readings checked before autonomous testing

## 5.1.22 Final BOM Summary

The Cheese v4 component architecture can be divided into six main systems.

<div align="center">

| System | Main Components |
| :--- | :--- |
| **Control** | EV3 Intelligent Brick |
| **Power** | EV3 Rechargeable Battery |
| **Movement** | Large Motor, Medium Motor, wheels and Ackermann steering |
| **Sensing** | 3 Ultrasonic Sensors + 1 Color Sensor |
| **Vision** | HuskyLens + Arduino Nano |
| **Communication** | EV3 cables + USB + I²C wiring |
| **Structure** | Technic beams, pins, axles and bushings |

</div>

A complete reproduction of Cheese requires more than buying the same components.

It also requires preserving:

- sensor placement,
- sensor height,
- camera angle,
- motor assignment,
- wheel geometry,
- steering geometry,
- wiring architecture,
- and calibration.

<p align="center">
  <strong>
    Components + Placement + Geometry + Connections + Calibration
    = Reproducible Cheese v4
  </strong>
</p>
