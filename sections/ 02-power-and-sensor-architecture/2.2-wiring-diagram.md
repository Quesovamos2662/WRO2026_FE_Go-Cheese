The wiring diagram is the map of Cheese’s electronic system. It shows where every active motor, sensor, camera component, and communication bridge connects.

The EV3 Brick is the center of the wiring system. Motors connect to output ports, LEGO sensors connect to input ports, and the Arduino Nano connects through the EV3 USB port so it can communicate with and power the HuskyLens camera.

---

## ❀ 2.2.1 Wiring Diagram Purpose ────୨ৎ────────୨ৎ────

The goal of this wiring diagram is not only to show cables. It is meant to make the robot easier to rebuild, debug, and explain.

<div align="center">

| Wiring Diagram Job | Why It Matters |
| :--- | :--- |
| **Shows port usage** | Makes it clear where each motor and sensor connects. |
| **Shows power paths** | Explains how components receive energy. |
| **Shows data paths** | Explains how sensors and camera information move through the robot. |
| **Labels unused ports** | Prevents confusion during rebuilding. |
| **Supports debugging** | Makes it easier to find loose, wrong, or missing connections. |
| **Shows v3 → v4 improvement** | Documents how the wiring became cleaner and easier to inspect. |

</div>

---

## ❀ 2.2.2 EV3 Port Assignment ────୨ৎ────────୨ৎ────

The EV3 Brick uses output ports for motors and input ports for sensors. The USB port is used for the Arduino Nano.

<div align="center">

| EV3 Port | Connected Component | Function | Status |
| :--- | :--- | :--- | :--- |
| **OUTPUT_A** | EV3 Medium Motor | Steering motor | Active |
| **OUTPUT_B** | EV3 Large Motor | Drive motor | Active |
| **OUTPUT_C** | Empty | Not used in current layout | Unused |
| **OUTPUT_D** | Empty | Not used in current layout | Unused |
| **INPUT_1** | Left ultrasonic sensor | Wall distance reading | Active |
| **INPUT_2** | Color sensor | Floor color / marker reading | Active |
| **INPUT_3** | Right ultrasonic sensor | Wall distance reading | Active |
| **INPUT_4** | Empty | Not used in current layout | Unused |
| **USB** | Arduino Nano | Powers and connects the camera bridge | Active |

</div>

Unused ports are included on purpose. A reproducible wiring diagram should show both active and unused ports so another person does not have to guess if something is missing.

## ❀ 2.2.4 Arduino Nano to HuskyLens Wiring ────୨ৎ────────୨ৎ────

The HuskyLens does not connect directly to an EV3 sensor port. Instead, it connects to the Arduino Nano, and the Arduino Nano works as the bridge between the camera and the EV3-based system.

The Arduino Nano receives power from the EV3 USB port using a **USB Type-A to USB Mini-B cable**. Then the HuskyLens connects to the Arduino Nano through jumper wires.

<div align="center">

| HuskyLens Pin | Arduino Nano Pin | Wire Function |
| :--- | :--- | :--- |
| **5V** | **5V** | Powers the HuskyLens. |
| **GND** | **GND** | Shared ground connection. |
| **SDA** | **A4** | I2C data line. |
| **SCL** | **A5** | I2C clock line. |

</div>

This connection lets the HuskyLens receive power and send camera information through the Arduino Nano system.

## ❀ 2.2.5 Wiring Procedure ────୨ৎ────────୨ৎ────

This is the order we follow when checking or rebuilding the wiring.

<div align="center">

| Step | Connection | What to Check |
| :---: | :--- | :--- |
| **1** | EV3 battery installed | Battery is charged and seated correctly. |
| **2** | OUTPUT_A → Medium Motor | Steering motor cable is connected firmly. |
| **3** | OUTPUT_B → Large Motor | Drive motor cable is connected firmly. |
| **4** | INPUT_1 → Left ultrasonic sensor | Sensor cable is not loose or stretched. |
| **5** | INPUT_2 → Color sensor | Cable does not block the floor sensor area. |
| **6** | INPUT_3 → Right ultrasonic sensor | Sensor cable is cleanly routed. |
| **7** | EV3 USB → Arduino Nano | USB Type-A to USB Mini-B cable is connected. |
| **8** | Arduino Nano → HuskyLens | 5V, GND, SDA/A4, and SCL/A5 jumper wires are connected correctly. |
| **9** | Cable routing check | No cable touches motors, wheels, steering linkage, or sensor view. |

</div>

This procedure helps prevent wiring mistakes before testing the robot. If the robot behaves strangely, checking the wiring in this order helps separate wiring problems from software or mechanical problems.

## ❀ 2.2.9 Final Wiring Check ────୨ৎ────────୨ৎ────

Before a test run, the wiring should be checked in a simple order:

<div align="center">

| Check | Why It Matters |
| :--- | :--- |
| **Battery seated correctly** | Prevents sudden power loss. |
| **Motor cables connected** | Ensures drive and steering respond. |
| **Sensor cables connected** | Ensures wall and floor readings are available. |
| **USB cable connected to Arduino Nano** | Ensures the camera bridge receives power. |
| **HuskyLens jumper wires correct** | Ensures camera power and I2C communication. |
| **No cables blocking moving parts** | Prevents steering, wheels, or sensors from being obstructed. |

</div>

This final check makes the wiring system easier to debug and helps prevent losing test runs because of simple cable mistakes.

## ✦ Final Wiring Summary ─── ⋆⋅☆⋅⋆ ───

The v4 wiring layout became easier to understand and maintain because every active cable has a clear purpose: motor control, sensor reading, camera communication, or power delivery.

Cheese’s wiring is centered around the EV3 Brick. The motors connect to output ports, the LEGO sensors connect to input ports, and the Arduino Nano connects through USB. The HuskyLens connects to the Arduino Nano using power, ground, and I2C signal wires.

The previous v3 lighting system is included as engineering evidence because it helped solve detection problems during testing. The current v4 layout is cleaner because the camera was lowered, the mount was simplified, and cable routing became easier to inspect.
